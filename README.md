# OpenGL CMake Template
This repo is a template I plan to build other projects on.  
It encompasses all of my OpenGL learning journey.  

This redering engine (if you can call it so) has:
- 2D, fly, orbit cameras
- 3D model loading .gltf and .obj (haven't tested others)
- Skybox
- Blinn-Phong shading
- Point, spot, direction lights
- Shadows for all 3 light types
- Forward rendering pipeline (for now)
- Multi-Sampling Anti-Alias
- Gamma correction
- ImGui user interface
- Post-Process effects
- Diffuse, specular, normal and displacement mapping
 
Sorry for the messy commit history since I was learning these concepts at the same time.
(Note: some 3D models are not commited in the repo)
